总结 #1

让房子替你干活，而不是让你伺候房子

核心逻辑：先定机器人怎么跑（地面无阻、家具不卡、基站有水电）→ 再让家电代劳（厨电、洗护、擦窗）→ 最后减少需要打扫的表面（台面零物品、封闭柜门、少造型）。这三件事全部要在水电交底之前落到图纸上，事后补就是砸砖。

线径与回路

常见偷工减料

  • 4mm² 偷偷换成 2.5mm²、1.5 代 2.5；不接地线或用细地线；线不分色
  • 管内接头、死线抽不动；强弱电共槽；冷热水同槽或间距 <15cm
  • 水管走地不试压 / 试压时没关进户总阀（数据无效）；线管不固定
  • 承重墙开长横槽；封槽之后才通知你验收——这是最狠的一招，务必约定封槽前必须到场

👵 四代宅 + 全屋米家预埋

适老（必须在水电 / 砌墙阶段做）

  • 全屋无高差：室内落差 ≤0.5cm；必须设门槛时 ≤3cm 并做斜角，或用长条地漏 + 同层排水实现淋浴区齐平
  • 主通道净宽 ≥90cm；门洞净宽 ≥800mm（至少一个卫生间，建议 850mm）；轮椅回转直径 ≥1.5m
  • 湿区防滑 ≥R10、干区 ≥R9；干湿分离、淋浴凳、恒温花洒、坐便器高 40–50cm
  • 扶手加固板 / 钢板预埋：马桶侧墙、淋浴区离地 85–90cm，承载 ≥100–150kg。事后打孔装扶手吃不住力
  • 紧急呼叫：马桶旁 / 床头 / 淋浴区防水拉绳，高位 90cm（如厕）+ 低位 10cm（跌倒），联动家人手机并考虑断电备用
  • 床下、走廊、柜底、马桶旁红外感应夜灯，无眩光多光源；床头双控

米家智能（水电前定稿）

  • 所有开关底盒拉零线（零火版），86 型加深底盒 ≥50mm（推荐 60mm）；单火版易频闪、关灯微亮
  • 灯光按场景分回路，别一房一路串死；上智能后可用无线贴墙开关替代传统双控
  • 窗帘盒内留常通电五孔/16A（距顶约 45cm）；单轨槽 ≥15cm、双轨 ≥20–25cm 且需 2 个插座
  • 弱电箱换大箱 + 独立电源 + 插排；预埋六类/超六类网线到电视柜、书房、各卧室；AC+AP 或有线回程 Mesh（100–150㎡ 约 3 台）
  • 网关放客厅电视柜/玄关，别塞金属弱电箱；2.4G / 5G 分离并设独立 SSID（多数米家设备只认 2.4G）；优先蓝牙 Mesh + 中枢网关，断网也能跑本地自动化
  • 摄像头墙角距顶 5–20cm 留插座；吊顶内毫米波人在传感器留零火线（老人静坐不灭灯）；燃气传感器、智能水阀、水浸传感器点位
儿童安全：30cm 以下插座安全门、家具倒圆防撞、柜体固定防倾倒、门缝防夹、窗户限位器 / 防坠落传感器、玻璃 3C；室内摄像头避开床与沙发。Shark L5 基站属于这一批——常通电插座 + 墙面收纳位，水电阶段一起定。

  • 工期与违约：写明开工竣工年月日（100㎡ 约 90 个工作日，行业经验值）；违约金每日合同价万分之三~千分之一，低于「每天 50 元」形同虚设；超 30 日可解约索赔。
  • 明写禁止转包 / 分包，工长换人须书面同意；施工安全责任由施工方承担；约定保修响应时限（如 48h 上门）。
  • 验收不合格：书面问题清单 + 拍照录像、拒签验收单；纠纷可协商 / 消协投诉 / 仲裁 / 起诉（110 号令第 25 条）。空气检测不合格应返工（第 29 条）。
  • 甲醛：板材 GB 18580-2017 强制 E1 ≤0.124mg/m³；GB/T 39600-2021 分 E1 / E0 ≤0.050 / ENF ≤0.025。有老人小孩优先 ENF 或 E0，并控制板材总用量（单件达标叠加后仍可能超标）。自住判定用 GB/T 18883-2022：甲醛 1 小时均值 ≤0.08mg/m³，检测前关闭门窗 ≥12h，委托 CMA 机构；别用工程验收标准 GB 50325 替代，便携仪只配粗筛。气味不能判定超标。
