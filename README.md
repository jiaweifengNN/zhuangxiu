- 户型图内部尺寸：玖月 106 为手写实测净尺寸；嘉启 90 / 嘉悦 113 为「仙爸探盘」CAD 标注。**2026-11-15 已拿到湖畔大观 A² 带完整尺寸链的户型图**（顶部横链 1634+2698+1762+1833+1708=9635、底部 2507+1370+5011+748=9636、各房间面积：客餐厅 24.31㎡ / 阳台 6.97㎡ / 厨房 4.64㎡ / 三卧 13.61、8.23、7.25㎡ / 两卫 3.39、4㎡），但**客餐厅净宽净进深、剪力墙、梁位仍需量房实测**；`huxing-duibi.html` 里湖畔 A² 的数据仍是旧版比例估算，待按新图重算。
